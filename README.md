# Rocky Stone Labs' Homebrew tap

```sh
brew install --cask thewhey-brian/tap/stillwater
```

| Cask | What it is |
| --- | --- |
| `stillwater` | [Stillwater](https://stillwater.rockystonelabs.com): a free menu bar monitor for Macs running coding agents. Also installs the `stillwater` command-line tool. |

Stillwater updates itself from inside the app; `brew upgrade --cask stillwater` works too. Problems and ideas:
https://github.com/Thewhey-Brian/stillwater-feedback/issues
